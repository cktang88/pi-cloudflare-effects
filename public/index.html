03 / ExperimentsSimulate a failure or disconnect＋

Controls unlock while the selected run is active.

A
Leave the observer

Close only this event socket. PiHarness keeps working.

B
Apply a deadline

Schedule a durable app timer that aborts the current operation in five seconds.

C
Restart the Durable Object

Force an abrupt object restart while Pi Durable work is pending. On activation, Pi Durable reloads its saved session and resumes the operation. This does not exhaust actual Worker memory.

ⓘ How recovery works
Durable means savedEvents are kept by the agent and sent again when the viewer reconnects.
Deadline means abortThis app-level timer calls PiHarness abort. It is not a Cloudflare execution timeout.
Replay is policyThe Hands view shows configured tool policy; the actual replay decision depends on the operation state.
Restart keeps Pi statePi Durable stores the transcript and pending tasks in Durable Object storage. Recovery can call the model again to continue from its saved state; it cannot restore hidden model activations.
