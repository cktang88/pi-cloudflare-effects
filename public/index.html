03 / Try itDisconnect, abort, or restart＋

These buttons work while a run is in progress.

A
Disconnect this page

Close the event stream. The run keeps going; reconnect to catch up.

B
Abort the run

Abort now, or schedule an abort in five seconds. The schedule is saved, so it fires even after a restart.

C
Restart the Durable Object

Force the agent's Durable Object to restart mid-run. Pi Durable reloads its saved conversation and carries on with the same run. (This calls ctx.abort(); it does not run out of memory.)

ⓘ How recovery works
Events are savedThe agent keeps the last 300 events and sends them again when this page reconnects.
The deadline is an abortIt is this app's own timer, which calls PiHarness.abort(). It is not a Cloudflare time limit.
Replay settingsThe Tools tab shows whether each tool may run again after a restart. Whether a given call does depends on where the restart cut it off.
What a restart keepsPi Durable saves the conversation and unfinished tasks in Durable Object storage. After a restart it asks the model again from that saved point; an answer that was mid-stream is retried.
